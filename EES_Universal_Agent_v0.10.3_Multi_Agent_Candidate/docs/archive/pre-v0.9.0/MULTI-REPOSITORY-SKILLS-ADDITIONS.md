# Multi-repository skills additions

This release adds five original specialist skills informed by Pascal Editor, React Bits, LangChain, and UI UX Pro Max. The skills cover editor/plugin contracts, React component distribution, LLM tool contracts, LLM evaluation/observability, and evidence-driven design intelligence. Their fifteen evaluation cases are fixture-validated only; real agent effectiveness remains unverified. See `references/multi-repository-attribution.md` for license boundaries.
