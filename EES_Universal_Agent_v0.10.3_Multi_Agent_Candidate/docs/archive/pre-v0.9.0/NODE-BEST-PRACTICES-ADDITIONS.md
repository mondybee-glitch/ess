# Node.js Best Practices additions

This release adds three original specialist skills informed by the public `goldbergyoni/nodebestpractices` repository:

- `nodejs-component-architecture`: business components, layers, configuration, error ownership, and graceful shutdown.
- `nodejs-outcome-testing`: response, state, outgoing call, message, and observability outcomes with failure-path testing.
- `nodejs-production-performance`: event-loop safety, observability, container runtime, lifecycle, and measured performance.

The additions are operational syntheses, not a verbatim copy of the source text. See `references/nodebestpractices-attribution.md` for attribution and license handling. The nine evaluation cases are defined and fixture-validated; real agent execution remains unverified.
