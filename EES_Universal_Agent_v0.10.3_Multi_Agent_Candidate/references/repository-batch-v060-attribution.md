# Repository batch v0.6.0 attribution and boundaries

This release contains original process guidance informed by public repositories. It does not copy source code, prompt catalogs, security templates, exploit procedures, model recipes, or third-party assets.

## Deferred or catalog-only sources

`awesome-selfhosted`, `Awesome-Hacking`, `the-book-of-secret-knowledge`, `public-api-lists`, and `Agent-Reach` are not copied into standalone skills. They are catalog/adapter sources whose freshness, external-link terms, credentials, or upstream behavior require source-by-source verification. Their use is limited to future source-triage or adapter work.

All security-sensitive material is defensive-only, authorized, non-destructive, and subject to human approval, scope, rate, privacy, and stop-condition controls.
