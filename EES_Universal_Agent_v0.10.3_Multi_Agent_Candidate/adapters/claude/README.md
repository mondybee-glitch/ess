# Claude adapter

For Claude Code, use root `CLAUDE.md` plus `AGENTS.md` and the EES core files. For Claude's web app, paste a concise instruction set and attach only the relevant knowledge files; repository scripts do not become executable merely because they were uploaded.

This package does not automatically configure every Claude product. Validate that the actual product in use loads the instructions, can access required files/tools, routes to a real skill path, and reports evidence accurately. API integration requires an explicitly configured credential and a separately approved live smoke test.
