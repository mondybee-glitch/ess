# Gemini adapter

**Local agent path:** use root `GEMINI.md` with Gemini CLI or another tool that explicitly reads that filename. **Gem web app/Gem:** paste the relevant instructions from `GEMINI_SETUP_AR.md` and attach the Markdown knowledge files that fit its upload limits; a ZIP does not automatically install code or tools.

Required conformance: route a task using the canonical registry, load the chosen skill, preserve evidence/status labels, and report unrun tests honestly. Live API use requires `GEMINI_API_KEY` configured outside source control. See `scripts/live_gemini_smoke.py`; running it is a separate, explicitly authorized live test.
