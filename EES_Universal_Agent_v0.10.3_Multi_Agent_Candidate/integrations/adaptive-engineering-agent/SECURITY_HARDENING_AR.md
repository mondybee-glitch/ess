# سجل إصلاحات الأمان — EES v0.7.8 Adaptive Merged

## ما تغيّر

1. **منع تنفيذ أوامر اعتباطية:** أزيل الاعتماد على قائمة حظر نصية قابلة للتجاوز. أصبح تشغيل الأوامر محصورًا بقواعد ضيقة لا تقبل `python -c` أو `node -e` أو shell wrappers أو فواصل/توجيهات shell. المسموح حاليًا: أوامر إصدار محددة، وتشغيل pytest بصيغة مقيدة، و`npm test` فقط.
2. **عزل مسارات الملفات:** تُرفض المسارات المطلقة ومسارات traversal، ويُتحقق من المسار بعد حل الروابط الرمزية لضمان بقائه داخل مساحة العمل.
3. **حماية طبقة التحكم:** الكتابة إلى مجلدات التكامل/runtime والمهارات والسجلات وملفات البيئة وملفات التحكم محظورة افتراضيًا.
4. **منع الاستبدال الصامت:** أداة الكتابة تنشئ ملفات جديدة فقط ولا تستبدل ملفًا موجودًا. هذا يقلل خطر تعديل الملفات دون مراجعة، لكنه يعني أن تحرير ملف موجود مباشرة غير مدعوم حاليًا؛ استخدم آلية patch/review مخصصة قبل السماح بذلك.
5. **حدود تشغيل أوضح:** حد لحجم الأمر والملف، مهلة تنفيذ، `shell=False`، stdin معطّل، وبيئة فرعية محدودة.
6. **اختبارات انحدار أمنية:** أضيفت اختبارات لحمولات حقن Python/Node، ومحاولات traversal، والكتابة إلى طبقة التحكم، ومحاولات استبدال الملفات.

## التحقق المنفّذ

- اختبارات تكامل الوكيل: 6/6 ناجحة.
- اختبارات التكامل مع EES: 2/2 ناجحة.
- مجموعة اختبارات EES الموجودة في `tests`: 16/16 ناجحة.
- `compileall` لسكربتات الوكيل: ناجح.
- تدقيق التوجيه: 0 أخطاء، 0 تحذيرات.
- سلامة أرشيف ZIP وفحص SHA-256 أُجريا على الحزمة الناتجة.

## ما لم يُثبت بعد

- لم يُجرَ اختبار حي مع مزوّد نموذج؛ يتطلب ذلك `EES_API_KEY` و`EES_MODEL` صالحين.
- لم يُثبت benchmark جودة على مهام هندسية واقعية؛ نجاح الاختبارات الهيكلية لا يثبت جودة المخرجات أو «التكيف» الفعلي.
- لم يُنفّذ تشغيل Docker معزول في هذا التحقق.
- لم تُربط بعد دورة feedback ببوابة تقييم وترقية تلقائية آمنة داخل محرك EES. لا تُرقِّ أي مهارة تلقائيًا دون تقييم مستقل ومراجعة بشرية وسجل تراجع.
- أداة الكتابة الحالية مقصودة أن تكون محافظة؛ تحرير الملفات الموجودة يحتاج نظام candidate patch مع diff وموافقة واختبارات، بدل فتح الكتابة المباشرة على كل ملفات المشروع.

## حالة الإصدار

**تحسن أمان مهم تم اختباره محليًا؛ ليس اعتمادًا إنتاجيًا نهائيًا.** قبل الإنتاج: نفّذ اختبار مزوّد حي، وsandbox فعليًا، واختبارات اختراق مستقلة، وbenchmark ممثلًا للمهام، ومراجعة بشرية للتغييرات.
