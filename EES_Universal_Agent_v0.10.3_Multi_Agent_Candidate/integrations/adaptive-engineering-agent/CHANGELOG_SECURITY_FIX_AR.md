# تغييرات الإصلاح الأمني

- استبدال الحظر النصي للأوامر بقواعد سماح ضيقة.
- رفض تنفيذ `python -c` و`node -e` وأوامر shell المركبة.
- تشديد التحقق من المسارات ومنع الخروج من مساحة العمل عبر traversal أو symlink.
- حظر الكتابة في runtime والتكاملات والمهارات والسجلات وملفات البيئة.
- جعل أداة الكتابة new-file-only لتجنب الاستبدال الصامت.
- إضافة اختبارات أمنية وانحدارية وتوثيق حدود التحقق.
